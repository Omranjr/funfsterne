# Template assets

These are **placeholders**, generated as flat grey PNGs at the right
dimensions. They exist so a freshly scaffolded app boots and builds — not so
it ships.

Replace all five before submitting to a store:

| File | Size | Used by |
|---|---|---|
| `icon.png` | 1024×1024 | app icon, and the wordmark on the sign-in / sign-up screens |
| `splash-owner.png` | 1284×2778 | native splash, the animated splash, and the home hero |
| `favicon.png` | 48×48 | web build |
| `android-icon-foreground.png` | 432×432 | Android adaptive icon foreground |
| `android-icon-monochrome.png` | 432×432 | Android themed icon |

`icon.png` and `splash-owner.png` are also referenced from `src/brand.ts`;
keep the filenames or update that file too.
